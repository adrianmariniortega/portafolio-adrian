PROYECTO DESTACADO

Mercado Público · Compra Ágil

Construcción de un flujo de extracción, almacenamiento, transformación y análisis de información pública utilizando API, Python, SQLite y Power BI.

DATA ANALYTICS · API · BUSINESS INTELLIGENCE

De datos públicos a información accionable

El proyecto busca estructurar información de Compras Ágiles de Mercado Público para facilitar su consulta, seguimiento y análisis.

FLUJO API → PYTHON → SQLITE → POWER BI
01

El desafío

Transformar información disponible a través de la API de Mercado Público en una estructura local que permita realizar búsquedas, seguimiento, segmentación y análisis.

  • Consultar información mediante API.
  • Gestionar resultados paginados.
  • Almacenar información histórica.
  • Mantener una base local actualizada.
  • Preparar información para Power BI.
02

La solución

Se diseñó un flujo que conecta extracción, almacenamiento, transformación y visualización.

Consideraciones técnicas

La API contempla control de cuota diaria por ticket. Además, pueden producirse errores de saturación o respuestas 504, por lo que el proyecto considera estrategias de reintento y ejecución de procesos masivos en horarios de menor demanda.
